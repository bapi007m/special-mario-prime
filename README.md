# React Platform Adventure — Bowser & Princess Peach v7

Uses full-body Mario Party Superstars artwork for Bowser and Princess Peach.
Princess Peach is visible in the castle throughout the boss section and is
marked rescued after Bowser is defeated.

Bowser is rendered much larger than the previous green fallback and his
collision area is aligned with the full character.

The images are loaded from Super Mario Wiki's documented artwork redirects.

Run:
```bash
npm install
npm run dev
```

Controls:
- Left / Right or A / D = move
- Space / Up / W = jump
- Stomp Bowser 5 times
